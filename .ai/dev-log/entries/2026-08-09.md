# 2026-08-09

Cilj dana: Sitne ispravke katalogа (reklasifikacija Atlantis), provera pretrage po domaćem nazivu, i nova funkcija — box ključnih reči na stranici detalja (IMDB + korisničke) sa sigurnim čuvanjem. Dogovoren obim za „Povezani filmovi" (TMDB) kao zasebnu fazu.

Uradjeno:

- **Atlantis The Lost Empire (id 972)** prepoznat kao crtani → `content_category='animated'` + fizički premešten `F:\Strano\Filmovi\… → F:\Animirano\Filmovi\…`; DB `relative_directory` ažuriran. Backup baze pre izmene (`core.db.bak-atlantis-*`).

- **Pretraga po domaćem nazivu — verifikovano da radi.** Glavni search (`useFilmiumFilters`) pretražuje `title` (domaći/prikazni naziv), `original_title`, `english_title`, plus opis/žanr/glumci. `filmium_media_localizations` tabela je prazna (0), nema odvojenog „domaći naziv" polja koje se ne pretražuje. Nalaz: lokalni naslovi iz editora (`editor_settings.basic.local_title_sr/hr/bs`) se NE pretražuju — moguće proširenje (nije rađeno).

- **Box ključnih reči na stranici detalja (nova funkcija).** Ispod DODATO/IZMENJENO, zaseban okvir:
  - Backend: `MediaRepository.update_keywords(item_id, keywords, editor_settings)` — parcijalni UPDATE koji menja SAMO `keywords` i `editor_settings` (ne dira ostala polja). `FilmiumService.update_keywords`. Novi endpoint `PATCH /media/{item_id}/keywords` (`MediaKeywordsRequest`). Regresioni test `test_update_keywords_preserves_other_fields` (title/godina netaknuti, keywords+user_keywords sačuvani).
  - GUI: `FilmiumKeywordsBox.tsx` — IMDB/TMDB reči (`item.keywords`) **plavo** (read-only), korisničke (`editor_settings.user_keywords`) **zeleno** (dodaju se Enter-om, uklanjaju „×"); duplikati (case-insensitive) se ne dodaju. `updateFilmiumMediaKeywords` (PATCH) + `refreshCatalog`. Tip `MediaItem` dobio `keywords?`. 4 GUI testa.
  - Odluka: IMDB reči u `keywords`, korisničke u `editor_settings.user_keywords` (re-enrich ne briše korisničke). Provenance = boja.

- **Nalaz (predpostojeći bug):** „Izmeni sadržaj" editor payload NE šalje `keywords`/`collection` → svaka izmena preko editora ih briše. Keywords box ovo zaobilazi (parcijalni PATCH), ali editor i dalje briše — čeka popravku (dodati keywords+collection u editor payload).

Stanje testova: 199 GUI + 453 Python filmium (uklj. nove).

Sledeće:
- **Povezani filmovi (TMDB)** — dogovoreno kao zasebna faza (obimno, mrežno). Traži: `tmdb_id` kolona na media_items (sad ne postoji), `tmdb_client.get_recommendations`, storage related-a + čuvanje `tmdb_id` pri enrich-u, backfill celog kataloga (~870 × 2 TMDB poziva, rate-limited → dugo, u pozadini), endpoint, GUI 3 reda (Povezani filmovi / Preporučene serije / Po žanru).
- Brze opcije pre toga: popraviti editor-wipe (keywords/collection u payload) + proširiti pretragu na lokalne naslove iz `editor_settings`.

Napomene/odluke:
- Restart CORE API obavezan posle ovog rada (novi PATCH endpoint + repo/servis).
- Backup-i baze ovog dana: `core.db.bak-atlantis-*`.
- Related NE postoji u bazi — potvrđeno; „povezani" izvor izabran = TMDB similar (fetch+čuvanje), raspored preporuka = 3 reda (Povezani/Serije/Žanr).

# 2026-08-09 — Sesija 2 (poslepodne)

Cilj: Editor „Updatuj" (auto-dopuna iz TMDB + srpska latinica + ključne reči, sa snimanjem), masovni `/update-filmium` cron u pozadini, i command palette u pretrazi. Usput otkriven i popravljen ozbiljan pre-postojeći bug gubitka podataka.

Uradjeno:

- **Editor dugme „Dopuni preko TMDB" → „Updatuj".** Serverska pipeline (`core/domains/filmium/auto_update_service.py::auto_update_item`) koju dele dugme i cron:
  - TMDB matching `tmdb_client.enrich_best` — varijante naziva (`title_variants`: skini redni broj / franšizni prefiks, npr. „John Wict 5 - Balerina" → „Balerina"), svaka sa godinom pa bez; plus `enrich_by_id` za ručni TMDB ID.
  - Domaći naslov/opis na **srpskoj latinici**: TMDB srpski naslov → transliteracija (`transliteration.py`, ćir→lat sa digrafima Lj/Nj/Dž); ako nema domaćeg opisa → prevod EN→SR (`TranslatorService.translate_pair`, naslov+opis jednim pozivom) pa latinica; ako nema engleskog naslova → prevede originalni (`source="auto", target="en"`).
  - Ključne reči i glumci = **unija** (samo dodaje, nikad ne briše). Fill-empty za skalarna polja. Snima u bazu.
  - Endpoint `POST /media/{item_id}/auto-update` (`AutoUpdateRequest{tmdb_id?, override_title?}`). GUI: reload iz baze posle akcije, override polje „TMDB naziv/ID" kad promaši.
  - „Mood tagovi" → **„Ključne reči"** vezane na `item.keywords`.

- **ROOT CAUSE — gubitak podataka (jutrošnji „editor briše keywords" bio je samo vrh).** `FilmiumService._normalize_create_item` je pri SVAKOM create/update gradio nov `MediaItemCreate` sa samo 10 polja i tiho bacao `english_title`, `english_description`, `cast_names`, `studio`, `director`, `keywords`, `collection`, `is_synchronized`, `editor_settings`. Popravljeno da čuva sva polja. Regresioni testovi (`test_filmium_update_preserves_fields.py`). Popravljen i WarGames (id 1837) na živoj bazi kao dokaz (48 glumaca + 15 keywords + eng naslov/opis vraćeni).

- **`MediaItemResponse` nije vraćao `english_description`** → dodato (+ `from_domain`). Editor sad veže `englishTitle`/`descriptionEnglish` iz baze i re-hidratira sva polja (`hydrateFromItem` + `reloadFromDb`) posle Updatuj/Sačuvaj — prikaz uvek odražava bazu.

- **Bulk cron `/update-filmium`** (`core/domains/filmium/auto_update_cron.py` + `scripts/filmium_auto_update_cron.py`): zaseban proces **bez vidljivog terminala** (pythonw + CREATE_NO_WINDOW + SW_HIDE). Lista svih filmova/serija u `data/filmium_auto_update/{queue,state}.json`, obrada jedan-po-jedan sa pauzom. `processed_ids` — Stop čuva dokle je stao; ponovni start **preskoči već obrađene, doda samo nove**. Resume na podizanju CORE-a (`core_lifespan` → `resume_if_active`, mrtav PID → relaunch). API `POST/GET .../auto-update/{start,stop,status}`.

- **CORE indikator (donji desni ugao, u `AppShell`).** Minimalan: naslov „Cron" + animirani krug + procenat; hover → glatka animacija u pun prikaz (progres, trenutni naslov, Stop). Boja okvira po stanju: zeleno aktivno, žuto zaustavljeno, crveno kritičan prekid.

- **Command palette u pretrazi** (`FilmiumTopBar`): `/` komande + `#` kolekcije. Fantom (ghost) preporuke, `CTRL+→` dopuni, `↑↓` biraj, `Enter` pokreni/prikaži. Kolekcijski filter (`useFilmiumFilters.collectionFilter`) prikazuje **i filmove i serije** iz kolekcije (po id-u). Popravljen bug: `/` i `#` unos se više NE tretira kao tekst-pretraga (ranije izbacivao sve).

- **Popravljene 3 pre-postojeće build greške** (blokirale `npm run build`): `mpvReposition` import u `FilmiumPlayer`, dva `item` undefined guarda u `FilmiumMediaDetailsPage`.

Stanje testova: **210 GUI + 673 Python**, sve zeleno; `npm run build` prolazi.

Dokumenti: `docs/superpowers/specs/2026-08-09-filmium-auto-update-design.md`, `docs/superpowers/plans/2026-08-09-filmium-auto-update-editor.md`, `…-cron.md`.

Sledeće:
- Epizode serija u bulk (`auto_update_episode`, TMDB metapodaci po epizodi) — jedino preostalo iz dogovora; zaseban, veći posao.
- „Povezani filmovi (TMDB)" — i dalje zasebna faza (iz jutrošnjeg unosa).
- Opciono: vizuelni „chip" aktivne kolekcije + pretraga po lokalnim naslovima iz `editor_settings`.

Napomene/odluke:
- **Restart CORE API obavezan** — živi server je vrteo staru verziju (stari `_normalize_create_item` i stari cron), zbog čega su raniji Updatuj/Sačuvaj i dalje brisali polja i bacali terminal.
- Cron stanje resetovano na `idle` na kraju sesije.
- Puna auto-detekcija preimenovanih spin-offova (Ballerina) nije garantovana — ručni override naziv/ID je siguran put.

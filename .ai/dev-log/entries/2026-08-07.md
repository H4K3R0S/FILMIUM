  - `core/media_player.py` (nov, CORE-nivo, deljen): `MpvPlayer` nalazi `bin/mpv.exe`; `play(video, window_id, geometry, subtitle)` pokreće mpv `--force-window=yes --osc=no --no-border --ontop --no-window-dragging --title=CORE-MPV-OVERLAY --input-ipc-server=\\.\pipe\core-mpv --sub-auto=all --slang=srp,scc,hrv,bos,eng --sub-file-paths=subs:subtitles:titl:titlovi:prevod` + `--geometry` (EKRANSKE koord.) + `--sub-file` ako je dat. `--wid` NAMERNO ne (WebView2 prekriva native child → samo zvuk). Kontrola preko JSON IPC pipe-a (`cycle pause`, `seek rel`, `fullscreen`, `quit`). `reposition(geometry)` = ctypes `FindWindowW`+`SetWindowPos` (lepi overlay uz region).
  - `apps/api/routers/player.py` (nov, CORE): `/api/v1/player/mpv/{status,pause,seek,fullscreen,stop,reposition}`.
  - `filmium_series.py`: `POST /{root}/play-mpv` (window_id, geometry, subtitle) → `resolve_playable_video` + `resolve_media_file` za prevod → `mpv_player.play(...)`.
  - GUI `filmiumPlayer.ts`: `getMainHwnd`, `getWindowGeom` (x,y,scale), `isMpvAvailable`, `playMpvVideo(...subtitle)`, `mpvReposition`, `mpv{Pause,Seek,Fullscreen,Stop}`. `lib.rs`: komande `core_main_hwnd` + `core_window_geom` (inner pos + scale); `vlc_player` mod uklonjen, Cargo `vlc` dep uklonjen.
  - `FilmiumPlayer.tsx`: engine toggle Web/Univerzalno/mpv (web isključen za test). mpv region = poster + Play dugme (NE auto-play — startuje samo na klik). `computeMpvGeometry` = rect regiona × scale → `WxH+X+Y`. Reposition listeneri (resize/scroll/ResizeObserver + Tauri onMoved/onResized) → `mpvReposition` (rAF-debounce) → overlay prati pomeranje/resize prozora. Stop na promenu engine/src.
  - Details `handleNativePlay`: za film prosleđuje srpski prevod (`subtitleSourceFor`, sr-prioritet) u `playMpvVideo`; serije auto (`--sub-auto`).

# 2026-08-16

Cilj: Detalj-stranica: zameniti stare preporuke sa tri odeljka (Povezani/Preporučeni/Po žanru) uz TMDB related; doraditi „Dodaj" modal (DnD indikator, prevod opisa EN→BS, polja originalni/domaći naslov).

## Urađeno
- Backend: RelatedTitle model + kolona related_tmdb (migracija v30); repository serijalizacija/parsiranje; TMDB client parsira `recommendations` (append_to_response) sa cap 20; auto_update (Updatuj) snima related_tmdb; MediaItemResponse izlaže related_tmdb.
- Frontend: helper filmiumRecommendations.ts (scoreRecommended = ključne reči>žanr>naziv, scoreByGenre, splitRelated owned-first, cascadeDedupe) sa 7 vitest testova; detalj-stranica renderuje tri odeljka (10 po odeljku); ne-owned kartice = crvena ivica + „Za preuzeti" badge → otvaraju Dodaj modal (prefill).
- Dodaj modal #2: DnD indikator na celom prozoru (brojač dubine, samo za Files) — isprekidana ivica + banner „Režim prevlačenja".
- Dodaj modal #3a: dugme „Prevedi (BS)" u domaćem opisu → endpoint POST /filmium/wishlist/translate (TranslatorService.translate_pair, fiksni bosanski).
- Dodaj modal #3b: polja Originalni naslov + Domaći naslov, trajno u wishlist bazi (kolone + migracija v31); TMDB pretraga ih puni.
- Sve merge-ovano u master (--no-ff), grana obrisana. Testovi: 765 backend + 7 gui, tsc čist.

## Sledeće
- Ručna preview-verifikacija u živoj app: posle „Updatuj" na naslovu proveriti odeljak Povezani + crvene ne-owned kartice; „Prevedi (BS)" u Dodaj modalu.
- Punjenje related_tmdb za NOVE importe (trenutno „samo unapred" preko Updatuj); po potrebi proslediti enrichment.recommendations i u import putanje.
- Opciono: „Prikaži još" preko 10 kartica po odeljku.

## Napomene/odluke
- related_tmdb se puni samo unapred (novi importi + ručni Updatuj); stari redovi ostaju NULL dok se ne osveže.
- Ne-owned poster koristi TMDB CDN (https://image.tmdb.org/t/p/w500), bez lokalnog keširanja.
- Migracije v30 (related_tmdb) i v31 (wishlist original_title/local_title) primenjuju se automatski pri sledećem pokretanju.

# 2026-08-16 — Sesija 2 — CORE disk skener + fantom, povezane particije, sistem gadgeti

Cilj: CORE: skener privatnog USB/diska sa nevidljivim fantomom (identitet, diff novih/izmenjenih, sektori), prepoznavanje da su particije jednog fizičkog USB-a jedan disk, real-time CPU/GPU/RAM gadget i gadget stanja (normal/minimal/hidden).

## Urađeno
- Faza 1 (jezgro, TDD): disk_snapshot_models, disk_scanner (deep scan, injektabilan walker), disk_diff (mtime+veličina), content_classifier (sektori boot/software/deljenje-DEKI/štampa-STAMPA/video/filmoteka Animirano-Domace-Ostalo-Strano), phantom_store (skriveni .core_phantom, HMAC potpis, PlainJsonCodec — enkripcija buduća), disk_scan_service orkestrator; 21 test.
- Faza 2: AutoScanCoordinator kači se na postojeći DiskMonitorService; scan_notification (format_report + Null/Callback/OsToast lazy win10toast→PowerShell toast, degradira bez pada).
- Faza 3: peek(mount) — lagani uvid u fantom bez walk-a; pri priključenju SAMO peek (ne pun scan), pun scan isključivo na poziv; API GET /api/v1/system/disks, /disks/peek, POST /disks/scan; disk_runtime deljeni servisi; startup wiring u lifespan; GUI disk panel gore desno.
- E: (RUFUS_BOOT, FAT) je write-protected → dodat ScanReport.phantom_written; skeniran G: → prvi pravi fantom (1080 stavki, hidden).
- Fizička topologija (physical_disk.py preko PowerShell Get-Partition/Get-Disk): E:+G: = jedan Kingston DataTraveler USB (fizički disk 4); related_partitions + physical_model/serial/bus u DiskIdentity; fallback upisa fantoma na upisivu sestrinsku particiju; peek traži fantom i na sestrama; film-nalaz (VIDEO+FILMOTEKA) u notifikaciji.
- Volume Label čitanje (GetVolumeInformationW, ctypes); GUI disk red: oznaka + Label + samo procenat (uklonjen tip USB/disk i reč 'slobodno').
- Sistem metrike: core/system/metrics (CPU/RAM psutil, GPU nvidia-smi→PS counter, degradira); GET /api/v1/system/metrics; GUI SystemMetricsWidget (poll 1.5s, boje po nivou, kritično ≥85%).
- Grupisanje particija u listi: DiskInfoResponse nosi physical_disk_number (keširana topologija TTL 15s); GUI spaja E:+G: u jedan red (Kingston, kombinovani %).
- Animacija punjenja barova (scaleX, stagger i*0.12s); gadget stanja normal/minimal/hidden (useGadgetState + localStorage) za oba widgeta; minimal sistem = samo kritične metrike, minimal disk = samo ne-sistemski (USB); hidden = restore handle.
- Perf widget premešten u zaglavlje (visina sata, bez okvira), ograničen na Dashboard; disk selekcija klikom (ne hover) da dugme Skeniraj bude dostupno; cycle ikonica skrivena, vidljiva samo na hover widgeta.
- Testovi: backend disk+metrike ~55, GUI vitest 7 novih (diskApi/metricsApi/useGadgetState), tsc čist; sve provereno u živom browseru (grupisanje E+G, metrike, stanja, hover).

## Sledeće
- Restartovati backend da /metrics ruta i peek-on-connect budu aktivni (stara instanca full-skenira pri priključenju).
- Po potrebi skinuti write-protection sa E: za fantom i tamo; inače je dovoljan fantom na G: (upisiva sestra).
- Opciono: temperature CPU/GPU u widgetu, podesivi pragovi/boje iz Settings, prikaz diff liste fajlova u hover detalju, grupisanje E+G u jednu kockicu u minimal disk modu.

## Napomene/odluke
- Enkripcija fantoma = plain JSON zasad; PhantomCodec interfejs ostavljen za buduću pravu enkripciju.
- Diff = mtime+veličina (brzo za ogromne diskove, bez čitanja sadržaja).
- Fantom hidden (SetFileAttributesW +h +s), write greške ne obaraju scan (phantom_written=False).
- GPU preko nvidia-smi (RTX 5060), fallback PowerShell GPU counter, pa None; CPU/RAM psutil.
- Specovi/planovi: docs/superpowers/specs/2026-08-16-disk-scanner-fantom-design.md + planovi Faza 1-3 i Faza 5 (metrike/gadget stanja).
